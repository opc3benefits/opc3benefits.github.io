## How the weekly rotation works
The homepage loads `/blog/posts.json` and shows 4 cards starting from the current ISO week index.

## Submitting to Search Engines
- Add Google Search Console HTML tag in `<head>` of `index.html` then verify and submit `sitemap.xml`.
- Add Bing Webmaster Tools meta tag similarly, verify, and submit the same sitemap.
